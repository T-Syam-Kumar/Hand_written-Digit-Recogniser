# 🧠 Handwritten Digit Classifier (MNIST)

A handwritten digit recognition project built using **PyTorch** and **Gradio**.  
This application allows users to **upload an image** or **use a webcam** to predict handwritten digits (0–9).

The project is designed to run smoothly in **Google Colab** and can also be deployed locally or on the web.

---

## ✨ Features

- Upload handwritten digit images
- Predict digits using webcam input
- CNN trained on the MNIST dataset
- Real-time prediction
- Browser-based interface using Gradio
- Beginner-friendly PyTorch implementation

---

## 🧠 Model Details

- Framework: **PyTorch**
- Architecture:
  - 2 Convolutional layers
  - Max Pooling
  - Fully Connected layers
- Dataset: **MNIST**
- Loss Function: CrossEntropyLoss
- Optimizer: Adam
